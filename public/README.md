# 把你的音频文件放这里

## 🎧 耳机音乐（点耳机播放）

**文件名：** `headphone.mp3`（也支持 `.wav` / `.ogg`）
**怎么触发：** 进入房间后，点击桌面上的耳机
**效果：** 单独的播放器，循环播放，可随时开关

## 🎵 背景音乐（进房间自动响起）

**文件名：** `bgm.mp3`
**怎么触发：** 点击"进入房间"后自动播放
**效果：** 房间里一直循环的环境音/轻音乐，右下角有开关

***

## 放好之后的效果

| 文件                    | 作用   | 触发方式             |
| --------------------- | ---- | ---------------- |
| `public/bgm.mp3`      | 背景音乐 | 进房间自动开 / 右下角按钮开关 |
| `public/headphone.mp` | 耳机音乐 | 点桌上耳机            |

两个互不干扰，可以同时播放（耳机音乐是重点，BGM 是底噪）。

***

## 例子

你可以去这些地方找免费 mp3：

- <https://pixabay.com/music/> （免费，无需注册）
- <https://www.free-music-archive.org/>
- 或者你电脑上的任何 .mp3 文件

下载之后重命名放进 `/workspace/public/` 就行，不用改任何代码。

如果想换文件名，在 `src/App.jsx` 里搜 `HEADPHONE_SRC` 和 `BGM_SRC` 改路径即可。
